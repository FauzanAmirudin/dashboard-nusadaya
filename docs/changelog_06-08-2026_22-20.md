# Dokumentasi Perubahan Sistem - Dashboard Nusadaya
**Tanggal Pembuatan**: 6 Agustus 2026, 22:20 WIB

Dokumen ini merangkum seluruh perubahan, modifikasi fitur, dan perbaikan bug yang dilakukan pada sesi pengembangan kali ini. Fokus utama perbaikan adalah form Pendaftaran Mahasiswa Baru (PMB), penyesuaian profil mahasiswa, fitur *auto-save*, serta perbaikan relasi database (Drizzle ORM).

---

## 1. Modifikasi Profil Mahasiswa (`mahasiswa/profil/page.tsx`)
- **Penghapusan Data Sensitif / Tidak Relevan**: Menghapus field Nomor Induk Kependudukan (NIK), NISN (Nomor Induk Siswa Nasional), dan Alamat Lengkap Sesuai KTP dari halaman profil mahasiswa.

## 2. Modifikasi Form Keterangan Pendidikan (Tab PMB - Tab 2)
- **Penghapusan Bagian PMB Lengkap**: Menghapus keseluruhan seksi "Informasi Tambahan (PMB)" yang sebelumnya mencakup negara tujuan, data pendamping (Tim Visit, Sosialisasi), referensi, mitra sponsor, dan koordinator. Validasi *error* untuk bagian tersebut juga telah dihapus sehingga proses simpan berjalan lancar.
- **Pembaruan Program Studi**: Menghapus opsi program studi lain dan membatasi (*hardcode*) pilihan Program Studi hanya menjadi satu opsi utama: **D3 Perhotelan**.
- **Pembaruan Peminatan (Sub Program)**: Menyesuaikan opsi peminatan menjadi tepat 4 pilihan (tanpa opsi lain). Opsi ini menggunakan ikon bendera (diambil melalui CDN `flagcdn`) untuk menghindari masalah tampilan emoji di OS Windows:
  - 🇲🇾 Malaysia-Hospitality
  - 🇹🇼 Taiwan-Hospitality
  - 🇸🇦 Timur tengah-Barista
  - 🇮🇩 Indonesia-Reguler

## 3. Modifikasi Form Keterangan Kesehatan (Tab PMB - Tab 3)
- **Pembaruan Golongan Darah**: Menambahkan opsi golongan darah yang sebelumnya kurang, sehingga menjadi daftar lengkap: `A+`, `A-`, `B+`, `B-`, `AB+`, `AB-`, `O+`, `O-`, dan `O`.
- **Penambahan Opsi Ukuran Baju**: Menambahkan opsi **"Lainnya"** pada *dropdown* Ukuran Baju. Apabila pengguna memilih opsi ini, form secara otomatis memunculkan kolom *input* teks tambahan (`clothingSizeOther`) agar ukuran baju dapat diisi manual.

## 4. Fitur Auto-Save / Penyimpanan Sementara (LocalStorage)
- Mengimplementasikan fitur penyimpanan sesi otomatis (API `localStorage` dari browser) pada keseluruhan halaman Penambahan Mahasiswa.
- Sistem merekam seluruh isian (kecuali file foto profil) setiap kali terjadi perubahan form. Fitur ini memungkinkan pengguna untuk memuat ulang halaman (*refresh*) atau kembali setelah keluar tanpa kehilangan data di tab sebelumnya.
- Data sementara di *local storage* ini akan secara otomatis dibersihkan begitu seluruh proses pendaftaran berhasil disimpan ke *database*.

## 5. Pembaruan Field Keterangan Orang Tua & Wali (Tab PMB - Tab 4, 5, dan 6)
- Memeriksa struktur tabel database (`studentParents`) dan memastikan semua field tambahan didukung (termasuk religion, nationality, email).
- Memperbarui antarmuka (*UI*) untuk melengkapi kolom yang hilang pada Data Ayah, Ibu, dan Wali:
  - **Agama**: Dibuat menggunakan format *Dropdown/Select* persis seperti form mahasiswa.
  - **Kewarganegaraan**: Dibuat konsisten menggunakan format *Dropdown* ("Indonesia" dan "Lainnya"). Jika memilih "Lainnya", akan muncul otomatis field input teks tambahan.
  - **Email**: Ditambahkan kolom input *email*.
  - **Pendidikan Terakhir**: Ditambahkan secara khusus untuk Wali (sebelumnya terlewat pada form Wali).
- Memodifikasi payload JSON di fungsi `handleSubmit` untuk memastikan nilai opsi "Lainnya" dipetakan dengan benar sebelum dikirimkan ke *backend*.

## 6. Perbaikan Konfigurasi Relasi Database (Drizzle ORM)
- **Bug Fix**: Memperbaiki masalah di mana *Drizzle Studio* *crash* atau menampilkan *error*: `Invalid relation "parents" for table "students"`.
- **Akar Masalah & Solusi**: Drizzle ORM memiliki aturan ketat mengenai deklarasi relasi ganda (*bidirectional relations*). Sebelumnya, tabel `students` memiliki relasi `many` ke `studentParents`, namun tabel `studentParents` tidak memiliki deklarasi balik. 
- **Tindakan**: Menambahkan blok `studentParentsRelations` dan `studentHealthRelations` ke dalam `apps/api/src/db/schema.ts` (menggunakan fungsi `one()`) sehingga seluruh skema tervalidasi dengan baik dan *Drizzle Studio* dapat berjalan normal kembali.
